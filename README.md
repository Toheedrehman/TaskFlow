# TaskFlow Frontend

React + Vite frontend for the Task Manager.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

This version includes a frontend-only authentication demo using localStorage.
The API service is already prepared for the Node/Express backend that will be connected next.

## Backend URL

Create `.env` from `.env.example`:

```env
VITE_API_URL=http://localhost:5000/api
```
